    How it runs

    How every project starts

    Four steps, in this order. You see working software early, and I share progress in short written updates.

    1. 01

      Scope

      We agree the problem and how success will be measured, using a sample of your data.

    2. 02

      Prototype

      A small working version on your data, so you see real software early.

    3. 03

      Harden

      Tests and safety checks, plus short written updates along the way.

    4. 04

      Hand over

      Notes, setup instructions and a walkthrough so your team can run it.
