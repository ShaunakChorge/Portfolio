    Speech emotion recognition project

    Hear the mood in a voice clip, live from the mic.

    This speech emotion recognition project is a neural network (a 1-D CNN, which reads audio as a sequence) that labels seven emotions in speech clips. It was trained on four public datasets and scored 93.87% on a random 20% test split. It comes with live microphone input and a web dashboard.

    The story

    The problem: finding the mood in a voice

    The problem

    Emotion lives in tone, pitch and energy, not in the words, so a text-based model is the wrong tool.

    What I built

    Four datasets are merged and each clip is altered to create more training examples. Audio features are extracted with librosa, then a five-block neural network learns from them. The result is served through notebooks and a Streamlit dashboard.

    How it is built

    Four public datasets, seven emotions

    1. 01

      Four public datasets (RAVDESS, CREMA-D, TESS and SAVEE) merged into 12,162 clips

    2. 02

      Each clip altered four ways with noise and pitch changes, giving 48,648 training samples

    3. 03

      librosa audio features: zero-crossing rate, energy and MFCCs (numbers that describe the sound of a voice), 2,376 numbers per sample

    4. 04

      A five-block 1-D neural network with steps to prevent overfitting (memorising the training clips), 7.19 million parameters

    5. 05

      A notebook for live microphone input

    6. 06

      A Streamlit dashboard: upload or record, then see class probabilities and waveform and spectrogram views

    Results

    Results and a test note

    Every number comes with how it was measured. The limits are part of the result.

    • Recognises seven emotions: angry, disgust, fear, happy, neutral, sad and surprise
    • 93.87% accuracy and a weighted F1 score of 0.94 (one number that balances missed cases against false alarms) on a random 20% test split
    • Per-emotion F1 scores between 0.92 and 0.97
    • Caveat: altered copies of one clip can land on both sides of the split, so the result does not prove it works on new speakers
    • Live microphone detection in a notebook and in the Streamlit dashboard

    FAQ

    Questions about emotion recognition

    What is speech emotion recognition?

    Speech emotion recognition is software that listens to a voice clip and guesses the emotion from tone, pitch and energy rather than the words. This project labels seven emotions: angry, disgust, fear, happy, neutral, sad and surprise. It reads features from the audio and passes them to a neural network.

    How accurate is speech emotion recognition?

    In this project, 93.87% on a random 20% test split. That figure does not cover new speakers, because altered copies of one clip can land on both sides of the split. Accuracy on unseen voices will be lower, so a client project would first measure it by splitting speakers apart.

    Can it work with my own recordings?

    It can be retrained on your recordings if they are labelled with the emotions you care about. Quality depends on the microphone, the language and the number of speakers. I would first test it on a sample of your audio and report how well it holds.
