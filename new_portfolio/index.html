    How a freelance project works

    Four steps, with short written updates along the way. No code is written until we agree on the scope.

    1. 01

      Scope

      We agree the problem and how success will be measured.

    2. 02

      Prototype

      A small working version on your data, so you see progress early.

    3. 03

      Harden

      Tests and safety checks, so it keeps working outside the demo.

    4. 04

      Hand over

      Notes and a walkthrough your team can follow to run and extend it.
