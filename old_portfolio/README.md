# Earlier portfolio (kept for reference)

This is the previous version of Shaunak Chorge's portfolio. It is not maintained and is not listed in the sitemap; its home page carries a `noindex` tag. The current site is in [`../new_portfolio/`](../new_portfolio/).

It is plain HTML, CSS and JavaScript. Each section in `components/` is loaded into `index.html` with `fetch`, so open it through a web server (for example `npx serve ..` from this folder, then visit `/old_portfolio/`), not by double-clicking the file.

The Download CV button points to the current resume PDF in `../new_portfolio/assets/`. Icons, fonts and the typing banner come from outside services, so those need an internet connection.
